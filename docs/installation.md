# Installation

Install TextIgniter using your preferred package manager depending on the framework you are using:

### Core Package (Vanilla JS / TypeScript)

```bash
# npm
npm install @mindfiredigital/textigniter

# yarn
yarn add @mindfiredigital/textigniter

# pnpm
pnpm add @mindfiredigital/textigniter
```

### React Wrapper

```bash
# npm
npm install @mindfiredigital/textigniter-react

# yarn
yarn add @mindfiredigital/textigniter-react

# pnpm
pnpm add @mindfiredigital/textigniter-react
```

### Angular Wrapper

```bash
# npm
npm install @mindfiredigital/textigniter-angular

# yarn
yarn add @mindfiredigital/textigniter-angular

# pnpm
pnpm add @mindfiredigital/textigniter-angular
```

### Web Component

```bash
# npm
npm install @mindfiredigital/textigniter-web-component

# yarn
yarn add @mindfiredigital/textigniter-web-component

# pnpm
pnpm add @mindfiredigital/textigniter-web-component
```
